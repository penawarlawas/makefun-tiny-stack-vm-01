A virtual machine for make.fun's tiny stack ISA. Implements every rule in ISA.md:
wrapping 32-bit arithmetic, all ten traps and their exit codes, the step and output
limits, and the edge cases the ISA names as the ones most implementations get wrong.

```sh
node main.ts
```
