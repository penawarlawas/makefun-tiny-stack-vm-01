A virtual machine for make.fun's tiny stack ISA, implementing every rule in ISA.md:
32-bit wrapping arithmetic, the ten traps with their own exit codes, the step and
output limits, and the edge cases the ISA calls out as the ones most implementations
get wrong.

## Run it

```sh
node main.ts
```
